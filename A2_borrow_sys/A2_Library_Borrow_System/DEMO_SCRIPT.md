# A2 Demo Script

## 1. อธิบายภาพรวม
"โปรเจกต์นี้เป็นระบบยืม-คืนหนังสือมหาวิทยาลัย พัฒนาด้วย Python โดยใช้ Class และ Object ในการจัดการข้อมูล Student, Book และ BorrowRecord และมี Library เป็นตัวจัดการระบบ"

## 2. อธิบาย 2D Array
"ใน main.py มีตัวแปร book_data ซึ่งเป็น 2D Array แต่ละแถวเก็บรหัสหนังสือ ชื่อหนังสือ และจำนวนทั้งหมด จากนั้นนำข้อมูลแต่ละแถวมาสร้าง Book Object"

## 3. อธิบายการยืม
"เมื่อเลือก Borrow ระบบรับ Student ID และ Book ID จากนั้นตรวจสอบว่านักศึกษาและหนังสือมีอยู่หรือไม่ และตรวจสอบจำนวนหนังสือ ถ้ายืมได้จะสร้าง BorrowRecord กำหนดวันคืนอีก 14 วัน และลดจำนวนหนังสือลง 1"

## 4. อธิบายการคืน
"ระบบค้นหารายการยืมที่ยังมีสถานะ Borrowed จากนั้นเปรียบเทียบวันปัจจุบันกับ Due Date ถ้าเกินกำหนดจะคำนวณจำนวนวันที่ค้าง แล้วเปลี่ยนสถานะเป็น Returned และเพิ่มจำนวนหนังสือกลับ"

## 5. อธิบาย File R/W
"โปรแกรมใช้ CSV เป็นไฟล์เก็บข้อมูลการยืม โดย load_data ใช้เปิดไฟล์แบบอ่าน และ save_data ใช้เปิดไฟล์แบบเขียน"

## 6. อธิบาย Try-Except
"ใช้ try-except เพื่อป้องกันโปรแกรมหยุดเมื่อเกิดข้อผิดพลาด เช่น FileNotFoundError เมื่อไม่มีไฟล์ และ ValueError เมื่อข้อมูลไม่ถูกต้อง"

## 7. อธิบาย Error
"ตัวอย่าง Error คือกรณี Student ID ไม่พบ ระบบจะตรวจสอบก่อนสร้างรายการยืม และ raise ValueError พร้อมแสดงข้อความให้ผู้ใช้ทราบ ทำให้โปรแกรมไม่สร้างข้อมูลที่ผิด"

## 8. ปิดการ Demo
"โปรแกรมนี้สามารถต่อยอดเป็นระบบ Login ระบบจองหนังสือ ระบบแจ้งเตือน ระบบค่าปรับ และเชื่อมต่อฐานข้อมูลจริงได้"
