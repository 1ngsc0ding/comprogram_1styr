## 1. วัตถุประสงค์
พัฒนาโปรแกรมสำหรับจัดการการยืม-คืนหนังสือของมหาวิทยาลัย สามารถตรวจสอบจำนวนหนังสือ บันทึกข้อมูลนักศึกษา กำหนดวันคืน และตรวจสอบหนังสือที่เกินกำหนดคืนได้

## 2. กำหนดปัญหาและประโยชน์
ห้องสมุดมีหนังสือหลายรายการและแต่ละรายการมีจำนวนไม่เท่ากัน หากจัดการด้วยมืออาจเกิดความผิดพลาด เช่น ยืมเกินจำนวนที่มี ไม่ทราบว่าใครยืม และติดตามหนังสือค้างคืนได้ยาก

โปรแกรมนี้เก็บข้อมูล Student, Book และ BorrowRecord เมื่อมีการยืมจะตรวจสอบข้อมูลและจำนวนหนังสือ จากนั้นกำหนดวันคืนอัตโนมัติ 14 วัน เมื่อคืนหนังสือ ระบบจะตรวจสอบกำหนดคืนและคำนวณจำนวนวันที่ค้างถ้ามี

## 3. การออกแบบโปรแกรม

### Class
- `Student` เก็บรหัสและชื่อนักศึกษา
- `Book` เก็บรหัส ชื่อ จำนวนทั้งหมด และจำนวนที่เหลือ
- `BorrowRecord` เก็บข้อมูลการยืมและสถานะ
- `Library` จัดการข้อมูลทั้งหมดและฟังก์ชันหลัก

### 2D Array
ใช้ `book_data` เป็น 2D array เพื่อเก็บข้อมูลตั้งต้น:

```python
book_data = [
    ["B001", "Python Programming", 3],
    ["B002", "Data Structure", 2],
    ["B003", "Computer Network", 4]
]
```

แต่ละแถวประกอบด้วย `[book_id, title, total_quantity]`

### File R/W
ใช้ไฟล์ `data/borrow_records.csv`
- `load_data()` อ่านข้อมูลด้วย mode `r`
- `save_data()` บันทึกข้อมูลด้วย mode `w`

### Try-Except
ใช้จัดการ `FileNotFoundError`, `ValueError`, `OSError` และข้อผิดพลาดทั่วไป เพื่อไม่ให้โปรแกรมหยุดทำงานทันทีเมื่อผู้ใช้กรอกข้อมูลผิดหรือเกิดปัญหากับไฟล์

## 4. การทำงานของโปรแกรม
1. เริ่มโปรแกรมและสร้างข้อมูล Student/Book
2. โหลดรายการยืมจาก CSV
3. แสดงเมนู
4. ผู้ใช้เลือกการทำงาน
5. ระบบตรวจสอบข้อมูลและทำงานตามเมนู
6. เมื่อออกจากโปรแกรม ระบบบันทึกข้อมูลลง CSV

### การยืม
รับ Student ID และ Book ID → ตรวจสอบนักศึกษา → ตรวจสอบหนังสือ → ตรวจสอบจำนวน → สร้าง BorrowRecord → กำหนดวันคืน 14 วัน → ลดจำนวนหนังสือ

### การคืน
รับ Student ID และ Book ID → ค้นหารายการยืม → ตรวจสอบวันคืน → คำนวณจำนวนวันที่ค้างถ้าเกินกำหนด → เปลี่ยนสถานะเป็น Returned → เพิ่มจำนวนหนังสือ

### การตรวจสอบค้างคืน
วนรายการ BorrowRecord ที่มีสถานะ Borrowed แล้วเปรียบเทียบวันปัจจุบันกับ Due Date
